# ربات مدیریتی + سلف تلگرام (نسخه کاملاً قانونی)

این پروژه با کتابخانه‌ی **Telethon** نوشته شده و برای اجرا روی **Railway** آماده شده.

## ⚠️ چرا «کاملاً قانونی»؟

تلگرام ارسال خودکار و زمان‌بندی‌شده‌ی پیام (تبلیغاتی یا هر نوع دیگر) به گروه‌ها را
**اسپم** می‌داند و می‌تواند اکانت شما را محدود یا بن کند — فرقی نمی‌کند فاصله‌ی
ارسال ۱ دقیقه باشد یا ۱ ساعت یا حتی رندوم. به همین دلیل **هیچ قابلیت ارسال
خودکار/زمان‌بندی‌شده در این ربات وجود ندارد**. به‌جای آن، یک دستور «ارسال بنر»
داریم که هر وقت خودتان بخواهید و با یک دستور دستی، پیام را به گروه‌های
منتخب می‌فرستد. بقیه‌ی قابلیت‌ها (منشی، آنتی‌گروه، مدیریت ادمین و ...) هم
کاملاً در چارچوب قوانین تلگرام هستند.

## ساختار پروژه (بدون فولدر)

```
main.py            کد اصلی ربات
requirements.txt    وابستگی‌ها
Procfile             دستور اجرای Railway
README.md            همین فایل
```

## پیش‌نیازها

1. یک اکانت تلگرام (همان اکانتی که سلف روی آن فعال می‌شود)
2. **API_ID** و **API_HASH**: از https://my.telegram.org وارد شوید → API Development Tools → یک اپلیکیشن بسازید و این دو مقدار را بردارید.
3. یک ربات معمولی از طریق **@BotFather** بسازید (`/newbot`) و **BOT_TOKEN** را بردارید. این ربات فقط برای فرآیند ورود استفاده می‌شود.
4. آیدی عددی خودتان را از رباتی مثل @userinfobot بگیرید تا به‌عنوان **OWNER_ID** استفاده کنید (این مانع می‌شود کس دیگری بتواند با ربات ورودتان وارد اکانت شما شود).

## مراحل دیپلوی روی Railway

1. یک پروژه‌ی جدید در Railway بسازید و همین فایل‌ها را (بدون فولدر) به‌عنوان یک ریپازیتوری آپلود/دیپلوی کنید (از GitHub یا Railway CLI).
2. در بخش **Variables** پروژه، متغیرهای زیر را اضافه کنید:

   | نام متغیر | مقدار |
   |---|---|
   | `API_ID` | همان‌طور که از my.telegram.org گرفتید |
   | `API_HASH` | همان‌طور که از my.telegram.org گرفتید |
   | `BOT_TOKEN` | توکن رباتی که از BotFather گرفتید |
   | `OWNER_ID` | آیدی عددی خودتان |
   | `SESSION_STRING` | خالی بگذارید — بعد از اولین ورود پر می‌کنید (پایین توضیح داده شده) |

3. Deploy را بزنید. در لاگ باید پیام «ربات ورود روشن شد» را ببینید.

## ورود به اکانت خودتان (فقط یک‌بار)

1. در تلگرام به ربات‌تان (همان که از BotFather ساختید) پیام بدهید: `/login`
2. شماره تلفن را با فرمت بین‌المللی بفرستید، مثلاً: `+989121234567`
3. کدی که تلگرام برایتان می‌فرستد را داخل همان چت وارد کنید.
4. اگر رمز دومرحله‌ای (Cloud Password) دارید، همان را هم وارد کنید.
5. ربات پیامی حاوی یک رشته‌ی طولانی (SESSION_STRING) برایتان می‌فرستد.
   **این رشته را کپی کنید و در Railway → Variables → SESSION_STRING قرار دهید و سرویس را دوباره Deploy کنید.**
   این کار باعث می‌شود بعد از هر ری‌استارت یا آپدیت روی Railway، دوباره مجبور به ورود نشوید.

بعد از این مرحله، به «پیام‌های ذخیره‌شده» (Saved Messages) خودِ اکانتتان در تلگرام
بروید و بنویسید: **راهنما**

## لیست کامل دستورات (در Saved Messages تایپ می‌شوند)

### عمومی
- `راهنما` — نمایش راهنمای کامل
- `راهنما بنر` / `راهنما گروه` / `راهنما منشی` / `راهنما امنیت` / `راهنما آنتی` — راهنمای هر بخش
- `پینگ` — تست سرعت اتصال
- `آیدی` — نمایش آیدی عددی شما

### یادآوری تایم‌دار (فقط در Saved Messages خودتان)
> این قابلیت **فقط** به خودِ شما (Saved Messages) پیام می‌فرستد، نه به هیچ گروهی. برای ارسال واقعی به گروه‌ها همچنان باید دستور دستی `ارسال بنر` را بزنید.
- `تنظیم دقیقه ارسال به سیو مسیج <عدد>` — مثال: `تنظیم دقیقه ارسال به سیو مسیج 10` (هر ۱۰ دقیقه یک پیام یادآوری به خودتان می‌رسد)
- `متن یادآوری سیو مسیج <متن>` — تغییر متن پیام یادآوری، مثلاً: `متن یادآوری سیو مسیج پینگ`
- `توقف یادآوری سیو مسیج` — خاموش کردن یادآوری
- `وضعیت یادآوری سیو مسیج` — نمایش فاصله‌ی زمانی و متن فعلی

### گروه‌ها
- `افزودن گروه <آیدی یا یوزرنیم>` — مثال: `افزودن گروه @mygroup`
- `لیست گروه‌ها` — نمایش شماره، نام و آیدی هر گروه
- `حذف گروه <شماره>` — مثال: `حذف گروه 2`

### بنر (ارسال دستی)
- `ثبت بنر` — با ریپلای روی یک پیام (متن/عکس/ویدیو)
- `بنر` — پیش‌نمایش بنر ذخیره‌شده
- `ارسال بنر <شماره گروه>` — ارسال دستی به یک گروه خاص
- `ارسال بنر all` — ارسال دستی به همه‌ی گروه‌های ثبت‌شده

### منشی
- `منشی روشن` / `منشی خاموش`
- `منشی متن <پیام>` — تنظیم پاسخ پیش‌فرض
- `پرسش پاسخ افزودن <سوال> | <جواب>`
- `پرسش پاسخ حذف <سوال>`
- `لیست پرسش پاسخ`

### امنیت
- `سکوت روشن` / `سکوت خاموش` — قطع/وصل موقت منشی و پاسخ خودکار
- `افزودن ادمین <آیدی>` / `حذف ادمین <آیدی>` / `لیست ادمین‌ها`

### آنتی گروه (حفاظت گروه)
- `آنتی گروه روشن <شماره گروه>` — حذف خودکار پیام‌های حاوی لینک/یوزرنیم و کنترل فلود از اعضای غیرادمین
- `آنتی گروه خاموش <شماره گروه>`
- `آنتی گروه وضعیت <شماره گروه>`

> نکته: آنتی‌گروه فقط زمانی کار می‌کند که اکانت شما در آن گروه دسترسی حذف پیام (ادمین) داشته باشد.

## نکات مهم

- **پایداری داده‌ها روی Railway**: فایل `bot_data.json` (تنظیمات شما) روی دیسک محلی سرویس ذخیره می‌شود. در پلن‌های رایگان/عادی Railway، این فایل بین ری‌استارت‌های معمولی باقی می‌ماند ولی ممکن است با هر Redeploy از صفر شروع شود، مگر این‌که یک **Volume** به سرویس متصل کنید (از تنظیمات Railway).
- **SESSION_STRING را در اختیار کسی قرار ندهید** — این رشته معادل رمز عبور کامل اکانت تلگرام شماست.
- این ربات هیچ پیامی را بدون درخواست شما به گروه‌ها ارسال نمی‌کند.
- برای رعایت بیشتر قوانین تلگرام، هنگام «ارسال بنر all» بین ارسال به هر گروه ۲ ثانیه فاصله گذاشته شده تا فشار ناگهانی به اکانت شما وارد نشود.

## عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| ربات به `/login` جواب نمی‌دهد | مطمئن شوید `BOT_TOKEN` درست است و سرویس روی Railway در حال اجراست (لاگ را چک کنید) |
| کد را وارد می‌کنم ولی خطا می‌دهد | کد را با فاصله بین ارقام بفرستید (مثلاً `1 2 3 4 5`) تا تلگرام آن را با پیام‌های خودکار قاطی نکند |
| بعد از هر دیپلوی دوباره باید لاگین کنم | مقدار `SESSION_STRING` را در Variables درست ذخیره نکرده‌اید |
| دستورات در Saved Messages کار نمی‌کنند | مطمئن شوید `SESSION_STRING` معتبر است و در لاگ عبارت «کلاینت سلف با موفقیت متصل شد» دیده می‌شود |
